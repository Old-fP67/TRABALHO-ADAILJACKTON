# Agro Termos Visuais

Crie um site educativo chamado “Dicionário de Agropecuária”, com o objetivo de apresentar de forma simples e visual até 15 palavras (verbetes) relacionadas à agropecuária.



Estrutura



O site deve funcionar no estilo de slides: cada verbete deve aparecer como um slide individua, permitindo ao usuário avançar e voltar entre os termos usando ### Navegação entre os slides

 

Não utilize botões tradicionais de **“Anterior”** e **“Próximo”**.

 

A navegação deve funcionar como uma apresentação de slides:

 

 

- Utilize **setas laterais discretas** (← e →) para avançar e voltar;

 

- Em celulares e tablets, permita **deslizar o dedo para a esquerda ou direita (swipe)** para trocar de slide;

 

- No computador, também deve ser possível utilizar as **teclas de seta do teclado**;

 

- As setas devem ficar nas laterais da tela e ter um design simples, combinando com a estética rural;

 

- O usuário deve perceber facilmente que pode deslizar para navegar;

 

- Mantenha a transição entre os slides suave e rápida, sem efeitos exagerados.

 



 

A navegação deve ser intuitiva e semelhante à de uma **apresentação de slides interativa**, mantendo o visual limpo e minimalista. Também pode haver uma barra de progresso ou indicação como “3 de 15" , é necessario tambem que os verbetes nao preencham a pagina inteira e sejam uma seçao do site , alem das secoes de titulo e participantes.



Cada slide deve conter:



- Nome do termo em destaque;

- Uma definição curta e fácil de entender;

- Uma pequena explicação ou exemplo de uso;

- Uma imagem ou ilustração relacionada ao termo, quando apropriado;

- Número do slide.



Verbetes



Utilize no máximo 15 termos de agropecuária, por exemplo:



1. Agricultura

2. Pecuária

3. Irrigação

4. Solo

5. Adubação

6. Fertilizante

7. Plantio

8. Colheita

9. Rotação de culturas

10. Agroecologia

11. Silvicultura

12. Pastagem

13. Pecuária extensiva

14. Pecuária intensiva

15. Agricultura familiar



As definições devem ser corretas, curtas e adequadas para estudantes, evitando textos muito longos.



Estilo visual



O design deve ser levemente minimalista, mas sem parecer excessivamente tecnológico ou futurista.



A estética deve transmitir uma sensação de campo, natureza, agricultura e ambiente rural, mantendo uma aparência moderna e organizada.



Utilize principalmente:



- Verde claro como cor principal;

- Marrom claro/terra para detalhes;

- Azul claro para complementar;

- Branco para fundos e espaços;

- Preto ou verde-escuro para textos.



Evite cores neon, gradientes exagerados, excesso de efeitos, aparência cyberpunk ou elementos futuristas.



Elementos visuais



Use detalhes sutis inspirados no ambiente rural, como:



- Folhas;

- Plantações;

- Silhuetas de montanhas;

- Tratores;

- Cercas;

- Grãos;

- Árvores;

- Texturas discretas de papel ou madeira;



Esses elementos devem ser discretos, sem deixar o site visualmente carregado.



Layout



O site deve ter:



- Uma capa inicial com o título “Dicionário de Agropecuária”;

- Uma breve frase explicando o objetivo do site;

- Um botão “Começar”;

- Slides individuais para cada verbete;

- Botões de navegação “Anterior” e “Próximo”;

- Indicador de progresso;

- Uma tela final simples com uma mensagem de encerramento.



O layout deve ser responsivo e funcionar bem tanto em computadores quanto em celulares.



Tipografia



Utilize uma fonte moderna, limpa e fácil de ler. Os títulos podem ter uma fonte levemente mais orgânica/rústica, mas sem exagerar.



Experiência



A navegação deve ser simples e intuitiva. As transições entre slides podem ter animações suaves, como um pequeno deslizamento ou fade, mas devem ser discretas.



O resultado final deve parecer um trabalho bem produzido sobre agropecuária, combinando organização, estética rural e modernidade, sem parecer um site corporativo ou futurista.
